How does this model work?
  1. Inputs: today's USDT close/volume and BNB close/volume (the 4 features picked by SelectKBest in your notebook).
  2. Scaling: each value is mapped to 0-1 using the training min/max (rebuilt from the notebook because the saved scaler was an identity).
  3. Prediction: 100 decision trees each vote a BTC price; the forest returns the average.
  4. Limits: it is a nowcast, not a next-day forecast, and trees cannot go beyond prices seen in training, so a new all-time high in BNB will make the estimate flat-line.
